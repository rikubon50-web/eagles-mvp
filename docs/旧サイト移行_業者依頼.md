# 旧サイト（agulaxmen.com）の移行について — 業者様への依頼内容

青山学院大学男子ラクロス部の公式サイトは、新サイト **https://aoyamaeagles.com** へ移行しました。
旧サイト agulaxmen.com のアクセスを新サイトへ転送したく、以下をお願いいたします。

## お願いしたいこと（案X：推奨）

**agulaxmen.com のDNSレコードを、新サイトのホスティング（Vercel）へ向ける変更**

| 種別 | ホスト名 | 値 |
|---|---|---|
| A | agulaxmen.com（ルート／@） | 76.76.21.21 |
| CNAME | www.agulaxmen.com | cname.vercel-dns.com |

- 上記の設定が反映されると、旧URL（ブログ記事・選手ページ・試合日程など）はすべて新サイトの対応ページへ自動転送（301）されます。転送ルールは新サイト側に実装済みです
- 反映後、旧サーバー（EC2）は停止いただいて問題ありません
- 反映までDNSの伝播で数時間〜1日かかることがあります

## あわせて確認させてください

1. **ドメイン agulaxmen.com の登録名義と更新期限**
   - 名義が御社の場合、部（または担当者）への移管は可能でしょうか。難しい場合は、少なくとも1年程度は更新を継続いただけると助かります（検索結果からの流入を新サイトへ引き継ぐため）
2. 旧サーバー上に、サイト以外で利用中のもの（メール転送・フォーム等）があれば教えてください

## 代替案（案Y：DNS変更が難しい場合）

旧サーバー（Apache）側で転送設定を入れていただく方法です。設定内容は同封の `legacy-redirect-apache.conf` をご参照ください。この場合、旧サーバーは転送のために稼働し続ける必要があります。
